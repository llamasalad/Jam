# Jam

## Description

Jam is a lowkey, self-hosted music player designed to give you full control over your personal audio library.

## Features

- **Configured with Capacitor to build and run a iOS mobile application with native APIS alongside the web interface**
- **Support for Navidrome backends**
- **Support for Spotify Canvas**
- **Fetches artist images from Apple Music**
- **Utilizes cloud services for storage and backend processes**
- **Various Navidrome features support, including a genre-based Smart Playlists**
- **Various Themes**
- **Gapless Playback**
- **Transcoding**
- **Lyrics**
